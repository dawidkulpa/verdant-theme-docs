# Verdant documentation

Buyer documentation for Verdant, a theme for Pterodactyl Panel 2.0.
Read it at https://dawidkulpa.github.io/verdant-theme-docs/.

This repository holds documentation only. The pages are generated from the theme's private source repository with
`scripts/publish-docs.py`; `_config.yml`, `support.md` and this README are edited here.
