# Support

- **BuiltByBit**: message the author of Verdant.
- **Discord**: direct message to **buggy121**.

## Include

- Verdant version (`php artisan p:extension:list`), panel and Wings versions, browser.
- What you did, what you expected, what happened, with a screenshot.
- For the player list: the agent's status in **Admin › Player list** and the game chosen for the egg or server.

Never send the panel's `.env` or `APP_KEY`, Wings tokens, API keys or passwords.
